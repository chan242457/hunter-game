# ⚔️ 용사 키우기: 마왕 토벌전 (Hero Slayer: Demon Subjugation)

> **고품질 다크 판타지 용사 액션 RPG & 시간대별 개성 넘치는 마물 토벌 로그라이크 서바이벌**
> **역동적인 검 휘두르기 액션 / 닉네임 커스텀 / 명예의 전당 TOP 5 랭킹 / 타인 공유 및 실시간 멀티 연동 지원**

---

## 🎮 게임 실행 및 타인 공유 방법

### 1. 일반 단독 플레이
- **`start_game.bat`** (또는 `index.html`)을 더블 클릭하면 기본 브라우저에서 즉시 실행됩니다.

### 2. 다른 사람(친구, 스마트폰, 다른 PC)과 함께 플레이 & 랭킹 연동 (강력 추천!)
- **`공유_서버_실행.bat`** 을 더블 클릭합니다.
- 내 컴퓨터 화면에 브라우저가 열리며, 콘솔 창에 **친구/스마트폰 접속 주소**가 표시됩니다:
  ```
  🖥️  내 컴퓨터(PC) 접속:     http://localhost:8080
  📱  친구 / 스마트폰 접속 주소: http://192.168.X.Y:8080
  ```
- **같은 Wi-Fi나 공유기에 연결된 누구나** 스마트폰이나 다른 PC의 웹 브라우저에서 위 주소(`http://192.168.X.Y:8080`)를 입력하면 별도 설치 없이 즉시 게임에 접속하여 플레이할 수 있습니다.
- 모든 플레이어의 점수가 **[명예의 전당 TOP 5]에 실시간으로 공유 및 동기화**됩니다!

---

## 🗡️ 신규 업데이트: 검 휘두르기 액션 & 랭킹 시스템

1. **실제 검 휘두르기 모션 & 화려한 초승달 검기 파동 (Sword Slash VFX)**
   - 손잡이, 황금 십자가드, 예리한 금속성 양날 검신이 전방을 호쾌하게 베어 넘깁니다.
   - 칼날 끝을 따라 펼쳐지는 눈부신 **초승달 검기 파동(Crescent Slash Wave)**, 잔상 트레일, 불꽃 스파크 연출!
   - 칼날이 닿는 순서에 맞춰 적들을 일도양단하는 실시간 순차 베기 타격 판정 적용.
   - **성검 엑스칼리버 진화 시**: 거대한 황금 대검과 3연속 쾌속 성스러운 검기 베기 폭풍!

2. **용사 닉네임 입력 & 영구 저장**
   - 메인 화면 상단에서 언제든지 원하는 용사 이름을 입력/변경할 수 있습니다. (기본값: `빛의 용사`)
   - 입력한 이름으로 명예의 전당과 실시간 공유 서버에 영구 등재됩니다.

3. **명예의 전당 TOP 5 랭킹 시스템 (Hall of Fame)**
   - 역대 최고 기록 상위 5개가 항상 보존되며, 신기록 달성 시 실시간으로 순위가 갱신됩니다.
   - 순위(🥇 1위, 🥈 2위, 🥉 3위, 4~5위), 용사명, 생존 시간, 토벌 마물 수, 도달 레벨, 달성 일자가 완벽히 기록됩니다.
   - 플레이 종료 시 5위 안에 진입하면 **"🏆 명예의 전당 TOP 5 신기록 달성!"** 축하 배너가 점등됩니다.
   - **기록 복사 / 주소 복사**: 버튼 클릭 한 번으로 친구들에게 내 기록이나 접속 주소를 클립보드로 공유 가능!

## 🕹️ 조작법
| 동작 | 키보드 | 마우스 / 터치 |
| :--- | :--- | :--- |
| **이동** | `W`, `A`, `S`, `D` 또는 `방향키` | 화면 드래그 (가상 조이스틱) |
| **순간 무적 회피** | `Space` | 화면 우측 하단 `[⚡ 회피 대시]` 버튼 |
| **천벌의 성역 필살기** | `Q` 또는 `E` | 화면 우측 하단 `[✨ 성역]` 버튼 |
| **레벨업 카드 선택** | **`1`, `2`, `3` 키** | 카드 직접 마우스 클릭 |
| **사운드 토글** | `M` | 화면 우측 상단 `[🔊 사운드]` 버튼 |
| **기본 공격 / 타겟팅** | **자동 조준 & 자동 발사** (사거리 내 가장 가까운 적을 조준) |

## 👑 인게임 실시간 성장 & 고대 유물 시스템

### 1. 용사의 5대 무구 & 초월 각성 (Awakened Weapons)
- **용사의 대검** + 매의 눈(치명타) $\rightarrow$ **★ 성검 엑스칼리버 (광속 삼중 황금 검기)**
- **비전 화염구** + 거인의 완력(공격력) $\rightarrow$ **★ 지옥불 메테오 (초거대 운석 낙하 & 지속 화염)**
- **서리 노바** + 마나 순환석(쿨감) $\rightarrow$ **★ 절대영도 블리자드 (전 화면 광역 빙결)**
- **천상의 심판** + 마력 자석석(자석) $\rightarrow$ **★ 신벌의 낙뢰 (소나기 천벌 벼락)**
- **수호 방패** + 질풍의 장화(이속) $\rightarrow$ **★ 이지스의 성벽 (6연장 방패 & 탄환 반사)**

### 2. 고대 유물 (Ancient Artifacts)
보물상자와 보스 처치 시 일정 확률로 영구 장착되는 전설 유물:
- ⏳ **시간의 모래시계**: 체력이 30% 이하로 떨어지면 3.5초간 슬로우 모션 & 무적
- 🪶 **뇌신의 황금 깃털**: 모든 치명타 공격 시 100% 확률로 주위 적들에게 벼락 연쇄 강타
- 🍷 **영원의 피 성배**: 적을 40마리 처치할 때마다 최대 체력이 영구적으로 +4 증가
- 🧤 **미다스의 건틀릿**: 골드 획득량 2배 & 공격받은 적이 5% 확률로 황금 석화 즉사

### 3. 고대 신전 영구 기도 봉헌
- 전투에서 모은 영웅 금화로 신전에서 8가지 영구 축복을 강화할 수 있으며, 모든 성장은 자동 저장됩니다.
